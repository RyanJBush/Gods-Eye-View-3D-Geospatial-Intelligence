Earthquake Cluster Explorer

Descriptive and historical view of one frozen catalogue snapshot. It is not a forecast and not a hazard estimate. Groups are DBSCAN outputs on map proximity only (an algorithmic grouping, not ground truth), and grid cells are an arbitrary baseline.

Drag to rotate, scroll to zoom, click a marker to select. Marker shape and color both show the group; size shows magnitude.
